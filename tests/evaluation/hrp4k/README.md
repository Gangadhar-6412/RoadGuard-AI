# HRP4K held-out evaluation sample

This directory contains ten image/YOLO-label pairs selected from the **test** split of HRP4K, with five pothole-positive and five clean-road negative images. The IDs are 30090, 30091, 30270, 30269, 30455, 30450, 30632, 30630, 30810 and 30811. They are used only to evaluate this checkpoint; they are not training data.

HRP4K was created by Hanshen Chen, Zhoulin Tu, Yu Zhao and Jianfeng Ye. Images and labels here were retrieved from the unofficial `dronefreak/HRP4K` Hugging Face redistribution of Zenodo v1.00 ([10.5281/zenodo.17522874](https://doi.org/10.5281/zenodo.17522874)). Its dataset card attributes the original release to CC BY 4.0; the subsequent complete v1.01 Zenodo record also lists CC BY 4.0 ([10.5281/zenodo.21941931](https://doi.org/10.5281/zenodo.21941931)). The paper describes HRP4K and confirms CC BY 4.0 for the dataset ([Scientific Data article](https://doi.org/10.1038/s41597-026-07317-w)). The selected IDs and source mirror are recorded above so this sample can be traced.

The model's training source remains a separate provenance issue: its card identifies a Roboflow dataset mirror whose Hugging Face metadata conflicts (`openrail` versus embedded CC BY 4.0 metadata). The original Roboflow project page currently states CC BY 4.0, but the conflicting redistributed metadata is not treated as proof that every mirrored artifact has permission. This evaluation sample avoids that disputed copy. Model-weight provenance and training-data licensing still need separate confirmation from the checkpoint publisher before redistribution or commercial deployment.
